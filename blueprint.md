# Racing Games Hub - Project Blueprint

## Overview
A framework-less web application (HTML, CSS, JS) designed for discovering and reviewing high-end mobile racing games. It features a modern, neon-themed UI, responsive design, and monetization through Monetag ads.

## Current Features
- **Game Discovery:** A grid-based display of top racing games.
- **Detailed Reviews:** Individual pages for each game with specs and download links.
- **Dynamic Search:** Real-time filtering of games by name or description.
- **Monetization:** Integrated popunders, vignettes, and banner ads.
- **Instagram Friendly:** Specific optimizations for the Instagram in-app browser.

## Planned Changes: AI Device Scanner
- **Purpose:** Increase user engagement and CTR by offering a simulated "compatibility check" for a graphics mod.
- **Functionality:** 
    - Input field for device name.
    - Simulated scanning animation with status updates.
    - Success message and "Unlock" button leading to a partner link.
